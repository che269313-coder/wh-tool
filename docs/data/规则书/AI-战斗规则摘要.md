# AI 战斗规则速记

这份文件供本地 AI 检索使用；具体数值、武器技能、计谋与例外始终以当前项目中的对应版本数据卡、阵营规则和分遣队规则为准。

1. 一回合依次经过指挥、移动、射击、冲锋、近战阶段。
2. 射击阶段：逐个选择能够射击的单位，选择合法目标与射击类型，再按攻击流程结算远程武器。
3. 近战阶段：先跟进；符合条件的交战单位或本回合冲锋单位按先攻和交替选择进行近战；最后重整。
4. 标准攻击流程：选择武器、目标与攻击次数；命中掷骰；造伤掷骰；护甲或无敌豁免；分配伤害与失去伤口。不觉疼痛按每一点将失去的伤口处理。
5. 计算所需的最小信息：攻击模型数、武器攻击次数、WS/BS、力量、AP、伤害和武器技能；目标的模型数、坚韧、护甲、无敌豁免、伤口和防御技能；以及适用的距离、视线、阶段、CP、计谋和分遣队效果。
6. 若资料未给出这些信息，先说明缺什么，不得用猜测的数值计算。
7. 警戒射击是对手移动阶段结束时的专门射击：满足目标与距离等条件时，通常仅未修正 6 命中且不能重掷；不要和常规射击混用。
