# 常用场景语料（人工审阅源）

本文件是 `../corpus.js` 的维护说明与扩展草稿，不会直接作为数值数据源。

| 用户表达 | 语义 | 必须动作 |
| --- | --- | --- |
| 禁军盾卫射击星际战士终结者，算平均伤害 | 禁军盾卫以远程武器攻击终结者小队 | 直接路由到 `calculate_combat`，`attackMode: "ranged"` |
| 禁军盾卫打星际战士终结者，一轮伤害 | 未指定攻击阶段的伤害比较 | 分别计算 `melee` 与 `ranged`，不将两项结果相加 |
| 近战呢 | 在最近一次明确战斗场景上切换攻击方式 | 复用最近场景并以 `attackMode: "melee"` 重算 |
| 图拉真有多少无敌 | 读取单位属性 | `get_unit_profile` |
| 那有掩体呢 | 在最近场景上增加掩体 | 复用记忆并重新 `calculate_combat`，`targetHasCover: true` |

新增条目只能描述意图和工具选择。武器数值、规则数值和最终伤害必须来自结构化数据卡与规则引擎。
