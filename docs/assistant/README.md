# 战术 Agent 扩展区

这里是 AI 行为与规则计算器之间的边界。Agent 可以理解场景、读取数据、记住对话并选择工具；它不能自行计算伤害，也不能修改 `engine.js` 的战斗规则。

## 文件职责

- `constitution.js`：不可违反的行为规则、工具使用原则与回答格式。
- `corpus.js`：可逐步扩展的术语、别名和常见场景语料；只帮助理解请求，不提供数值事实。
- `tactical-agent.js`：通用的模型调用循环、工具调用循环和浏览器本地记忆。它不导入计算器。
- `corpus/`：为语料的人工审阅版本、来源记录和后续拆分预留的位置。

## 接口边界

`docs/app.js` 是唯一的适配器：它把 `find_units`、`get_unit_profile` 和 `calculate_combat` 注入 Agent。计算器仍由 `buildSelectedRoundPayload()` 和 `simulateScenario()` 处理，返回结果后 Agent 只负责解释。

## 确定性计算路由

`corpus.js` 可为已覆盖的、表达明确的战斗问题返回一个确定的工具调用。例如“禁军盾卫射击星际战士终结者，算平均伤害”会直接调用本地 `calculate_combat`，不会先交给模型判断，也不依赖 API Key 或军表。

路由只处理已知别名、攻击方式和计算意图都齐全的场景；不完整、歧义或尚未收录的表达仍由 Agent 结合工具进行澄清。新增路由时要同时新增测试，且只能把别名和意图放入语料，数值仍必须来自数据卡和规则引擎。

当用户已给出双方单位和伤害意图、但没有说明攻击方式时，路由会分别计算近战与远程；两项结果不会相加。短续问如“近战呢”“远程呢”会复用最近一次场景。汇总还会提醒掩体、半程、冲锋等未声明条件，并列出当前数据卡中带开关、且已被规则引擎建模的技能。

## 记忆

Agent 在浏览器 `localStorage` 中保存最近 12 条用户/助手自然语言消息，以及最后一次成功计算的单位、攻击方式和明确战场条件。不会保存完整工具 payload、API Key 或军表副本。后续“那目标有掩体呢”可据此复用上一场景；新明确条件始终覆盖旧记忆。

## 如何扩展

1. 新增稳定行为约束，修改 `constitution.js` 并给出测试。
2. 新增术语或常见中文说法，修改 `corpus.js`，不要把未核验的数值写进去。
3. 新增能力时，先定义工具契约；在 `app.js` 实现受限适配器；保持 Agent 不依赖计算器内部状态。
4. 数据卡、军表和规则文本仍放在原有 `docs/catalogs/`、`docs/rules/` 与 `docs/data/` 分层中。
