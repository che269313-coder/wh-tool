## 四、发现与说明

**1. 引擎数值计算与外部 Wathammer 完全一致（0 项不一致）。** 全部 52 项用例在 1000 次外部模拟下 |Δ| ≤ 0.052；其中 14 项以 20000 次外部模拟复核后 |Δ| ≤ 0.024。

**2. 唯一的软件问题不在引擎，而在 app.js 的词条→字段映射缺口（app.js:2094 正则仅覆盖 步兵/载具/巨兽/工事/泰坦级）：**
   - 【反飞行 N+】（星际战士：伊卡洛斯火箭巢、双联伊卡洛斯火箭巢、铁雨天爪阵列等）不会被转换成 criticalWoundThreshold，对飞行目标按普通造伤结算；
   - 【反灵能者 N+】（死亡守卫：诅咒瘟疫丧钟；帝皇禁军：处决者巨剑等）同样未转换；
   - 影响：用户在 UI 选择这些武器对对应目标时，本地计算偏低（对比"预期映射"用例：反飞行2+ 伤害 0.920 vs 现状 0.409；反灵能者2+ 1.324 vs 0.889）。引擎本身在 effects.criticalWoundThreshold 被正确设置时与外部完全一致（见 anti-fly-*-intended、anti-psyker-*-intended 用例），所以修复只需在 app.js:2094 的 aliases/正则中补充 飞行(flying)、灵能者(psyker)。
   - 备注：docs/bug-report/deathshroud-ranged-anti-infantry/ 记录了同类的"洪流+反步兵"历史缺陷，该缺陷已在 app.js:2083-2096 修复（本审计的 torrent-anti-2plus 与 anti-infantry-4plus-torrent 用例确认修复有效）。

**3. 外部 1000 次模拟噪声实测：** 初始标记不一致的 anti-vehicle-2plus（Δ=-0.090）与 melta（Δ=-0.131）在 20000 次复核后收敛到 Δ=+0.021 / -0.009，均为 1000 次样本噪声（高方差用例 SE 可达 ±0.09）。若需更紧的判定，建议外部模拟数 ≥ 5000。

**4. 引擎实现细节与外部语义一致（经用例确认）：**
   - 致命一击命中（lethal）跳过造伤骰直接进入豁免（engine.js:421-427, 443-446）；
   - 毁灭伤害（devastating）在暴击造伤时变为致命伤害跳过豁免（engine.js:452）；
