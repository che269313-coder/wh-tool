# 通用武器能力覆盖审计

> 更新日期：2026-08-09。规则依据为 Git 历史中的原始 `11版核心规则简中.pdf` 第 79–85 页（24.03–24.38）。本文件取代 2026-08-08 版本；旧版本把“未启用词条的 payload 与外部随机结果接近”误判成支持，不能作为覆盖证据。

## 覆盖原则

“已实现”必须同时满足：

1. `keyword-dictionary.js` 能把中英文/OCR 别名解析为稳定语义，不依赖阵营、单位或武器名称。
2. 需要战斗状态的能力通过显式上下文归约，不能假设永远生效或永远不生效。
3. 会改变当前攻击链的能力必须改变最终 payload 或引擎结果；合法性与生命周期能力必须明确允许/阻止武器进入攻击。
4. 至少有一个确定性测试证明启用与未启用的结果不同。

## 24.03–24.38 武器能力矩阵

| 规则 | 稳定语义 | 实际行为 | 状态 |
| --- | --- | --- | --- |
| 针对 X Y+ | `anti-keyword` | 目标关键词匹配时降低暴击致伤阈值 | 已实现 |
| 突击 | `assault` | 突进后仅允许突击武器进行远程攻击 | 已实现 |
| 爆炸 X | `blast` | 目标每 5 个模型，每件武器获得 X 枚额外攻击骰；无 X 时按 1 | 已实现 |
| 劈砍 X | `cleave` | 所有攻击选择同一目标时，目标每 5 个模型获得 X 枚额外攻击骰 | 已实现 |
| 近距离 | `close-range` | 交战状态下允许非凶兽/载具射击；常规射击时与其他远程武器组二选一 | 已实现 |
| 毁灭伤害 | `devastating-wounds` | 暴击致伤转为按单次攻击限制在一个模型上的致命伤 | 已实现 |
| 额外攻击 | `extra-attacks` | 近战选武器时可选择所有额外攻击武器，并在可能时再选择一件其他近战武器；仍按自身 A 属性攻击；按模型数量阻止重复选择普通近战武器 | 已实现 |
| 危险 | `hazardous` | 每件被选择的危险武器在攻击后测试；1–2 失败，普通单位受 1 致命伤，纯凶兽/载具受 3 | 已实现 |
| 重型 | `heavy` | 未交战、非本回合部署、且没有模型移动超过 3 英寸时命中 +1 | 已实现 |
| 无视掩体 | `ignores-cover` | 取消目标掩体造成的 BS 劣化 | 已实现 |
| 曲射 | `indirect-fire` | 允许不可见目标；给予掩体、禁止命中重投，并同时执行未修正 6/4 命中下限与武器自身 BS | 已实现 |
| 骑枪/迅猛冲锋 | `lance` | 本回合冲锋后造伤 +1 | 已实现 |
| 致命一击 | `lethal-hits` | 暴击命中默认自动致伤；玩家可按武器关闭该策略，让暴击命中继续掷造伤骰 | 已实现 |
| 热熔 X | `melta` | 半射程内 D+X，支持 `D6+X` 等表达式 | 已实现 |
| 单发/一次性武器 | `one-shot` | 武器级“本场已使用”状态会阻止再次选择 | 已实现 |
| 手枪 | `pistol` | 作为近距离的兼容别名，使用同一合法性规则 | 已实现 |
| 精准 | `precision` | 玩家选择后，攻击优先分配给联合单位中的可见角色群组 | 已实现 |
| 灵能 | `psychic` | 可忽略不利 BS/WS/命中修正，并自动触发仅对灵能攻击生效的防御规则 | 已实现 |
| 速射 X | `rapid-fire` | 半射程内每件武器获得 X 枚额外攻击骰 | 已实现 |
| 连击 X | `sustained-hits` | 暴击命中产生 X 个额外命中，支持数字与 D3 | 已实现 |
| 洪流/喷射 | `torrent` | 自动命中 | 已实现 |
| 双联 | `twin-linked` | 默认重投失败的造伤骰；玩家可按骰面改选，包括重投成功骰以追求暴击造伤；与较弱的单位重投规则并存时不降级 | 已实现 |

此外，24.01 的“关键词后缀”已经统一实现：例如 `致命一击：载具`、`连击1：步兵/野兽` 只在目标拥有对应关键词时进入 payload。重复的同名能力不叠加，数值能力选择对当前结算最有利的一项。

## 非武器核心技能边界

致命破灭、不觉疼痛、先攻、火力平台、领袖、独行特工、斥候、隐匿、辅助、超重型机甲等也位于 24 章，但不是武器资料中的方括号武器能力。它们应分别进入伤亡、阶段、运输、部署、可见度或联合单位模块，不应伪装成武器数值修正。

## 回归入口

- `node tools/validate-rules.mjs`：解析、上下文归约、关键词后缀、合法性与数值修正。
- `node tools/validate-combat.mjs`：危险反噬、精准分配、灵能条件 FNP、曲射双重阈值。
- `node tools/validate-architecture.mjs`：确保 app 只消费公共词典/归约器，并且通用状态没有退回阵营分支。
