# DeepSeek 审核复核与待裁定（2026-08-10）

本文件只登记不能在当前证据和计算契约内安全解决的事项。DeepSeek 的结论未被直接采信；已逐项用原始 JSON、生成物、解析器和回归测试复核。

## 已确认并修复

- 规则装配曾丢弃持有者自己的 `weaponAttackModifiers`，且大部分阵营级命中、攻击次数、力量、穿甲、伤害效果虽能解析却没有装进武器结算。
- 阵营防守效果没有进入致伤条件归约；多份无敌豁免叠加时错误选择了更差的阈值。
- 反关键词缺少角色、恶魔、步行机、史诗英雄别名，复合目标与“非凶兽/载具”语义错误，`速射 D6+3` 丢失骰式加值。
- 繁转简脚本把非中文 Unicode 送入本地代码页，破坏 `Brôkhyr`、`Ûthar`、非断行连字符等英文原文。
- 网站数据生成器把 `wargear` 条目并入技能，并错误展开非默认编成；冠军/普通队员模型档案不稳定。
- 19 个网站阵营原来全部只有原文。现在对可由现有计算器安全表达的 531/3071 条阵营及单位规则生成中立效果；复杂项继续显示原文。
- 欧克审核所列的重掷范围、瓦戈条件、领导范围、近战相位、目标排除等确认错误已修；另补了“达卡闪击”只给闪击加农炮、且只对非凶兽/载具目标 A+6。
- 新增致伤暴击阈值与速射武器攻击次数两种中立效果；千子仪式、星界军号令、恐虐祝福、黑暗契约等多选规则改为明确控件，避免互斥效果同时生效。

## DeepSeek 结论中不准确或过度推断的部分

1. **炼狱之主·邪恶漩涡不是“仅近战”。** 当前原始数据写的是领导单位时“该单位中模型装备的武器”获得连击 1，没有近战限定。因此实现不附加 `phase: melee`。
2. **“现有 `incoming-hit-minus` 足以实现压制”不成立。** 压制是射击后施加给另一个单位、跨阶段持续、并在该单位以后作为攻击方时生效的目标状态；当前计算器只有本轮攻防双方的即时归约，没有跨单位、跨回合状态所有权。直接挂到施加者会算错方向。
3. **不是所有含骰子文字的技能都能直接接现有 effect。** “每阶段只重掷一颗骰”、按附近模型数量递增、指定武器/灵能武器、互斥选择、首次失败后失效等机制，若套用全局重掷或全武器加值会系统性高估。生成器现已对这些模式采取保守拒绝或专用控件，而不是追求表面覆盖率。

## 待你裁定 / 需要新设计

### 1. 压制状态

建议新增独立的战斗状态层，记录“施加者、受影响单位、开始/结束时机、适用近战或远程、施加所需命中条件”。在此之前，压制类规则保持原文，不用方向错误的即时防守 effect 近似。

### 2. 单颗骰重掷与次数上限

`hit-reroll` / `wound-reroll` 当前表示某类骰面或全部失败骰可重掷，不能表示“解决该单位全部攻击时只重掷一次”。需要决定是扩展引擎的共享重掷预算，还是继续仅供查阅。

### 3. 特定武器与动态规模

灵能武器、某个具名武器、每有一个邻近模型 A/S +1（最高 +2）等规则需要武器标签作用域和数值控件。当前无法保证只修改正确的武器，已禁止通用编译器把它们放大为全武器效果。

### 4. 数据卡静态属性与技能覆盖冲突

- 守密者“闪耀神盾”写持有者 Sv 3+，结构化卡片基础 Sv 为 4+；需要 `save-override` 或确认基础卡片是否已应包含装备效果。
- 若干护盾技能正文给 4+/5+ 无敌豁免，但结构化卡片的静态无敌豁免为空或为不同数值。需要统一原则：基础 profile 是否包含默认装备，还是全部由所选装备规则覆盖。
- 无阈值或空文本的“不觉疼痛/痛苦无感”不能从名称可靠推断数值，应补权威来源，不能猜测。

### 5. 欧克分遣队稳定 ID

原始分遣队文本缺少 5 个分遣队及其 25 个计谋/强化的英文标题，生成物目前使用 `detachment-N` / `source-ordinal-N`。直接替换会改变已发布的存档键；自行翻译又不能证明与官方英文一一对应。建议你决定：

- 保留旧 ID 为永久兼容别名，再补项目暂译 slug；或
- 等官方英文来源后一次性迁移并提供存档升级。

### 6. 本轮明确暂缓

分遣队技能全面实现、跨阶段致命伤、复活/移动/士气/资源池、首次失败后失效等非单轮伤害机制不在本轮优先范围。它们保留完整原文，未标成“计算支持”。
