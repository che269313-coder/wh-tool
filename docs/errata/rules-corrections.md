# 规则版本勘误账本

本文件只记录“原始资料与当前有效规则之间为什么不同”，便于以后集中复核更新历史。它不是运行时补丁表：程序、结构化数据和生成器始终直接表达当前有效版本，不得在计算链中先加载旧规则再套补丁。

## 记录规范

- 每条勘误使用稳定编号，注明旧来源、当前规则、影响范围、处理位置和确认依据。
- 修改实现时直接修正当前规则真相源及测试；不要新增按勘误编号、技能名或版本号执行的条件分支。
- 原始 PDF 保持不改，便于追溯；可检索文本若忠实来自旧 PDF，也可保留原文，但必须由本账本说明差异。
