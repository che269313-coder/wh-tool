# DeepSeek 审核修复记录

## 问题

网站阵营规则只有原文、欧克部分规则实现错误；同时规则装配、关键词、Unicode 转换和数据卡生成存在独立缺陷，导致技能被漏算、错算或数据损坏。

## 根因

- 网站阵营生成器没有结构化效果层；旧欧克生成器依赖宽松正则且缺少条件作用域。
- 应用层只合并了部分单位/联合单位效果，遗漏持有者武器修正及多数阵营效果。
- 关键词解析把排除条件当正向条件，且数值解析仅接受纯数字。
- 繁转简脚本逐字符调用依赖代码页的转换函数，错误处理非 CJK Unicode。
- 数据生成器未区分 wargear 与能力，也未按默认编成建立模型角色。

## 修复

- 新增保守型阵营规则编译器、专用阵营规则控件及公共效果类型；复杂或无法精确表达的规则只显示原文。
- 修正规则归约和武器 payload 装配，补齐阵营攻防效果、武器专属攻击加值与最佳无敌豁免选择。
- 扩展关键词语义、骰式攻击加值、模型档案与 Unicode 安全转换。
- 对 DeepSeek 指出的欧克项目逐条按源文本覆写，并补充达卡闪击。

## 验证

新增装配、关键词、转换、数据卡、网站阵营、欧克规则和详情面板回归测试；全量测试与项目验证脚本作为合入门禁执行。

## 预防

生成规则必须通过公共 effect schema；互斥选择、单颗骰重掷、具名武器和动态规模不得由宽松正则自动升级为全局效果。无法安全归约的项目统一登记在 `docs/audit/DeepSeek审核复核与待裁定-2026-08-10.md`。
