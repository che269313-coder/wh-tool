# Bug 诊断胶囊与修复记录：互斥武器档案被强制选中

## 诊断胶囊

| 栏位 | 内容 |
| --- | --- |
| **1. 现象** | “等离子手枪（标准）/（过载）”等最多选一档案会默认强制选中一个；角色同时装备手枪和其他枪时，常规射击分配因此被迫进入手枪组。 |
| **2. 证据** | `applyExclusiveWeaponDefaults` 在没有 `defaultSelected` 或装备匹配时仍回退到 `members[0]`；武器控件对 `selectionGroup` 使用 radio，选中后不能取消。 |
| **3. 问题假设或根因** | 已确认根因是把“最多选一项”误建模成“必须且只能选一项”，初始化和交互两层都强化了同一错误假设。 |
| **4. 诊断策略** | 用纯函数测试未指定默认档案时应全不选、显式默认时才选中一项；用架构测试约束 UI 使用可取消的 checkbox，继续由公共互斥逻辑关闭同组其他项。 |
| **5. 超时策略** | 若装备导入无法区分“拥有武器”和“本次选择档案”，则不增加武器名特判，分离装备状态与本次攻击选择状态。 |
| **6. 预警策略** | 若修复要求识别“等离子”“标准”“过载”等名称，说明仍在按具体武器耦合，必须撤回。 |
| **7. 用户可见交互修正** | 互斥档案默认可以全部不选；勾选其中一个会取消同组其他项，再次点击可取消当前项。 |
| **8. 验收** | 失败测试证明旧逻辑强制选择；修复后覆盖零选、一选、切换与取消，并确保手枪/其他远程武器分配校验仍然有效。 |

## 五件套

1. **报告人**：用户在 2026-08-09 实际检查角色远程武器选择时发现。
2. **复现步骤**：选择同时拥有等离子手枪档案和其他远程武器的角色；观察初始化及控件是否允许不选择任何等离子档案。
3. **根因分析**：`selectionGroup` 被错误解释为恰好选一，而规则和计算器需要的是至多选一。
4. **修复方案**：使用中立的可选互斥初始化函数；没有显式 `defaultSelected` 时全不选，控件使用 checkbox，启用时继续关闭同组兄弟项。
5. **验证方式**：规则纯函数测试、架构/DOM 静态契约和全量回归。
