# GitHub Pages 静态前端

本目录就是可以发布到 GitHub Pages 的网站根目录。

在 GitHub 仓库设置中选择：

- Source: Deploy from a branch
- Branch: `main`
- Folder: `/docs`

页面本身不依赖 Node.js。`engine.js` 是本地规则计算引擎，`app.js` 负责手机界面、军表导入、伤口管理和 AI/外部计算器调用。

资料文件只保存在当前浏览器本地，不会自动上传到 GitHub。请不要把 API Key、规则书 PDF 或个人资料提交到公开仓库。

## 使用方式

- 在“军表”页一次导入一份或两份军表；应用会保留联合单位、模型构成和装备。
- 也可以直接把军表粘贴到军表页的文本框，选择进攻方或防守方导入，无需保存文件。
- 点击单位可查看数据卡属性、设置每个模型的当前/最大伤口，或移除阵亡模型。总览会随之更新。
- `data/帝皇禁军/帝皇禁军-全部数据卡.json` 收录随附禁军 PDF 中的 18 张数据卡；扫描卡同时保留逐页 OCR 原文，方便按单位定位。
- `data/星际战士/星际战士-全部数据卡.json` 收录星际战士数据卡索引中的全部 104 个页级条目，完整表格保留在 `数据卡-可检索.md`。
