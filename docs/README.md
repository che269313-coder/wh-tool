# 战术助手 · Warhammer 40,000

这是一个面向 Warhammer 40,000 第 11 版玩家的免费网页工具，可导入军表、查看数据卡和分遣队规则，并模拟射击或近战造成的伤害。

## 在线使用

**[立即打开战术助手](https://che269313-coder.github.io/wh-tool/)**

无需安装或注册，手机和电脑浏览器均可直接使用。

## 主要功能

- 导入双方军表，保存联合单位、模型、装备与当前伤口。
- 浏览帝皇禁军、星际战士、死亡守卫的数据卡、技能、武器和分遣队。
- 根据导入的军表预设分遣队与角色增强，也可以手动调整。
- 支持同阵营内战和同名单位，两边的军表规则与 Buff 相互独立。
- 模拟命中、造伤、豁免、伤害、击杀模型数和全歼概率。
- 支持常见通用武器规则，并按实际条件显示可选项。
- 显示技能修正后的有效骰子阈值和重投选择。
- 所有军表与设置默认只保存在当前浏览器中。

## 使用步骤

1. 打开[在线版](https://che269313-coder.github.io/wh-tool/)。
2. 在“军表”页面导入或粘贴双方军表。
3. 在“计算”页面选择进攻单位、防御目标和远程/近战模式。
4. 根据战场情况展开通用武器条件、分遣队和技能选项。
5. 点击“本地模拟 1,000 次”查看平均伤害、分布和击杀概率。

不导入军表时也能直接搜索数据卡；分遣队默认关闭。

## 分遣队与增强

- 当前包含帝皇禁军 10 个、星际战士 24 个、死亡守卫 10 个分遣队。
- 增强只会出现在符合规则限制的角色下，例如仅限终结者或灵能者的增强不会提供给普通角色。
- 持有者效果与联合单位效果分别计算，护卫不能装备增强。
- 无法准确进入伤害模拟的规则仍保留完整原文供玩家查阅。
