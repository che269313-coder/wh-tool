2. **默认装备名与数据卡武器名匹配**：**0 个不匹配**。315 个单位的 `defaultEquipment`/`isDefaultWeapons` 全部能在对应 `docs/data/<阵营>/*-数据卡.json` 的 weapons 词表中找到（含 砌刀→大砍刀、垂铳→鼻涕虫枪、壬虫利爪→首领骨剑 等错字条目的映射结果）。
3. **合入状态**：`docs/rules/factions.js` 目前仅注册 4 阵营（禁军/星际战士/死亡守卫/欧克兽人），orks 的 21 条别名已合入；其余 8 个 OCR 阵营的 JSON 待跑 `apply-pdf-extraction.mjs`。合入时必须保留各自 `unitAliases` 块（该脚本已支持），否则 3.2/3.3 中的译名差异单位将失去搜索能力。

## 五、建议

1. **不重新提取**：抽样 5 页证实 砌刀/垂铳/丢哥哥乏眼/壬虫/壬子 均存在于原始扫描 PDF，重 OCR（同工具、200dpi）结果一致，属源扫描件清晰度/字形问题而非提取 agent 错误。提高 dpi 或获取重排版 PDF 才可能改善。
2. **人工修正 pdfName 错字（3 处，低优先级）**：泰伦「有翼泰伦壬虫」→有翼泰伦王虫；吞世者「恐虐恶魔壬子」「有翼恐虐恶魔壬子」→王子。仅影响展示文本，别名已保证可搜索。
3. **ork pdfNameEn 英文乱码（8+ 处）**：BEASTB088、B0卫2、WUJRRBOY、卫AINBOSS、MORKANATJT、RNekInMega Armoyr、r具、工事 等，建议人工修正或从官方英文名回填，用于英文界面展示。
4. **疑似错字待核对（砺万/死枪/橙武器/蒂轮/屠子/魔改手铳铁扳手）**：defaultEquipment 已落规范名，数据正确；若追求 pdfDefaultEquipment 原文精确，可对 orks p36/p40/p56/p64/p53/p33 单独人工比对。
5. **合入检查项**：跑 `apply-pdf-extraction.mjs` 前确认 8 个未合入阵营 JSON 的 `unitAliases` 完整（已核 100% 覆盖），合入后用 `army-list-aliases.test.mjs` 回归。
