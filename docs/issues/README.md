> 本目录集中登记**需要人工审核**与**已知遗留**的问题，含各轮 AI 审核记载。
> 约定：
> - 新发现的待审项统一放入本目录，命名 `<主题>待审核-<日期>.md`（旧文档沿用原名）；
> - 状态列含义：`待审核`=需人工裁定 / `遗留`=已知限制或设计欠账 / `记录`=问题已修复，仅留诊断档案 / `生成`=工具自动维护；
> - 处理完的项目在状态列标注 `已解决` 并简述处理位置，不需要删除档案。
>
> 历史审核过程文档（已完成审计、审核规则、官方身份提取产物）仍在 `docs/audit/`；
> 旧文档内部如引用 `docs/audit/...` 路径且目标已迁至本目录，请按本汇总对照。
