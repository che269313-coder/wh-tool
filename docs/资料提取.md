# 资料提取

本文只规定如何把一个队伍的原始资料变成当前架构可消费的数据卡、技能和分遣队包。架构说明见 [项目架构.md](项目架构.md)，审核方法见 [审核机制.md](审核机制.md)。

## 1. 归档原始资料

每支队伍使用独立目录：

```text
docs/data/<队伍>/
├── 原始规则书.pdf
├── 数据卡-可检索.md
├── 分遣队规则-11版原始文本.txt
├── 分遣队规则-可检索.md
└── <队伍>-结构化数据卡.json
```

同一队伍的数据卡、分遣队、分数表、勘误依据和原始 PDF 都放在该目录。`docs/data/detachments/` 只作为尚未接入队伍的待整理资料区，已接入后应移入队伍目录。

PDF 用于本地核对，不提交 Git；`.gitignore` 已排除 `docs/data/**/*.pdf`。可检索文本、JSON 和必要的来源说明可以提交。

规则书定义的公共武器词条放在 `docs/data/规则书/`，不要复制进每个队伍目录。

## 2. 从模板建立结构化数据

以 `docs/data/模板/数据卡模板.json` 为字段基准。提取顺序：

1. 建立页码/单位索引，确认没有漏页、重复页或跨页表格断裂。
2. 提取基础属性、模型构成、关键词、默认装备和全部武器档案。
3. 保留技能原文；为可计算技能声明稳定规则 ID 和公共 effect，不用技能显示名控制行为。
4. 标记武器多选一档案；多选一必须允许全不选，不能默认强制某一档案启用。
5. 提取分遣队规则、计谋、增强、点数、限制与完整原文。
6. 用 40k.app/官方英文资料复核英文身份；找不到时使用稳定暂译，并写入 ID 复核表，不阻塞接入。

原始资料若与当前版本勘误冲突，程序数据直接表示当前正确版本；勘误依据记录在 `docs/errata/`，不要在运行时代码里叠加“旧规则 + 补丁”。

## 3. 允许修改的文件

普通队伍提取可以修改：

- `docs/data/<队伍>/`。
- 该队的 `docs/rules/<faction>.js`、`<faction>-identities.js`。
- 该队的 `docs/rules/detachments/<faction>.js`。
- 该队生成配置、别名、审计报告和测试夹具。
- `factions.js` 的该队注册项与 `index.html` 的该队脚本加载项。
- 由通用 schema 驱动、只在该队规则声明出现时渲染的小型选项控件。

普通提取不得修改：

- `docs/engine.js` 的通用骰子和伤害流程。
- `docs/rules/effects.js`、`effect-schema.js`、`resolver.js` 的公共语义。
- `docs/app.js` 的全局计算流程或按技能名写 UI 分支。
- 其他队伍的数据卡、技能、分遣队生成物和别名。

如果仅靠已有公共 effect 和通用控件无法准确表达规则，先停止实现并报告维护者，不要为了“先跑起来”在队伍文件中写旁路。报告需包含原文、适用阶段/方向/对象、叠加关系、期望输入输出和建议的中立语义。

已经明确决议为暂不计算、只展示原文的规则不重复上报，例如“狮门英杰”；继续保持 `status: "仅供查阅"` 即可。

## 4. 生成

数据卡和单位规则使用该队既有生成器。分遣队可以只生成一队：

```powershell
node tools/generate-detachment-rules.mjs --faction=adeptus-custodes
node tools/generate-detachment-rules.mjs --faction=space-marines
node tools/generate-detachment-rules.mjs --faction=death-guard
```

不传 `--faction` 时会重建当前安装的全部分遣队包。日常更新优先使用单队参数，并在生成前后比较其他队伍文件哈希。

生成物不得手工修改；发现解析错误时修复原始结构化文本或生成器，然后重新生成。

## 5. 提取自检

- 数据卡数量、单位名、页码和原文索引一致。
- 每个武器档案的 A/命中/S/AP/D/关键词完整。
- 通用武器词条使用公共关键词字典，没有复制成队伍技能。
- 每个规则使用稳定 ID；中文改名不会改变行为。
- 每个效果声明阶段、进攻/防守方向、对象和 `owner/unit` 作用域。
- 增强只可分配给角色；护卫没有增强槽。
- 单队生成没有改写其他队伍文件。
- 无法计算的规则保留完整原文并明确标记，不做近似模拟。

完成后按 [审核机制.md](审核机制.md) 执行全量门禁。
