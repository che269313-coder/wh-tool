# 战术助手 · Warhammer 40,000

面向 Warhammer 40,000 第 11 版玩家的免费网页工具。它可以导入双方军表、查看数据卡和分遣队规则，并模拟一轮射击或近战造成的伤害与击杀概率。

## 在线使用

**[立即打开战术助手](https://che269313-coder.github.io/wh-tool/)**

无需安装或注册，手机和电脑浏览器都可以直接使用。GitHub Pages 更新后若仍显示旧页面，请刷新缓存或使用无痕窗口重新打开。

## 能做什么

- 导入进攻方和防守方军表，保留联合单位、模型数量、装备和当前伤口。
- 浏览帝皇禁军、星际战士和死亡守卫的数据卡、技能与武器档案。
- 识别军表中的分遣队与增强，并允许玩家在计算页面调整。
- 支持同阵营内战：双方使用相同单位时，军表、分遣队和 Buff 仍各自独立。
- 选择远程或近战攻击，模拟命中、造伤、豁免、伤害和击杀模型数。
- 显示伤害分布、击杀分布、全歼概率和平均有效伤害。
- 支持速射、热熔、连击、致命一击、曲射、手枪、额外攻击等通用武器规则。
- 根据技能和防守效果更新有效命中/造伤阈值及重投选择面板。
- 军表与设置保存在当前浏览器，不会自动上传。

## AI 工具调用

AI 不是计算器的替代品。聊天模型只负责理解中文场景、查找单位和解释结果；命中、造伤、豁免、伤害和击杀概率始终由本地 `engine.js` 运行 1,000 次模拟得出。对局数据与数据卡解析都留在浏览器中，发送给模型的是问题、当前军表摘要和必要的规则摘录。

要启用此功能，在“设置”中配置支持 OpenAI 兼容工具调用的模型服务。推荐部署仓库内的 Cloudflare Worker 并把它的 `/api/chat` 填入 AI 地址；Worker 的部署步骤见 [worker/README.md](worker/README.md)。当模型不支持工具调用时，普通规则问答仍可使用，但数值问题不会伪造计算结果。

AI 的提示词宪法、常用场景语料、工具循环与本地记忆已独立放在 [docs/assistant/](docs/assistant/README.md)。它会在浏览器本地保留最近 12 条对话和最近一次计算场景，便于继续追问“那有掩体呢”；这个模块负责理解和编排，计算器与数据卡继续使用原有架构，不被 AI 提示词污染。

## 快速开始

1. 打开[在线版](https://che269313-coder.github.io/wh-tool/)。
2. 进入“军表”，粘贴或导入双方军表。
3. 进入“计算”，选择进攻单位、防御目标和攻击类型。
4. 按实际战场情况展开通用武器条件、分遣队和技能选项。
5. 点击“本地模拟 1,000 次”查看结果。

不导入军表也可以直接搜索数据卡进行计算；此时分遣队默认关闭。

## 分遣队与增强

- 当前收录帝皇禁军 10 个、星际战士 24 个、死亡守卫 10 个分遣队。
- 导入军表后会预设军表中记录的分遣队，玩家仍可自行更换或关闭。
- 增强只能分配给符合条件的角色；终结者、灵能者、特定人物类型等限制会自动过滤。
- 有些增强只影响持有角色，有些会影响其领导的整个联合单位，计算器按规则原文区分。
- 暂时无法准确模拟的移动、部署、目标点或资源规则仍会保留完整原文供查阅，不会用近似数值误导玩家。

## 数据与隐私

- 军表、模型伤口和计算设置默认只保存在浏览器本地。
- 项目不会自动上传军表或个人资料。
- 可选 AI 功能需要玩家自行配置服务地址和 API Key；Key 不写入仓库。

## 本地运行

项目是静态网页。在仓库根目录运行：

```bash
python -m http.server 8080 --directory docs
```

然后访问 <http://localhost:8080>。

维护者只需阅读 [ARCHITECTURE.md](ARCHITECTURE.md)。阵营数据统一用 `node tools/build-data.mjs --check` 重建并验收。
